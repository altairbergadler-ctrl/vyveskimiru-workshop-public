# Оттиск из скана: серверный контракт

Все пути находятся под APP_BASE_PATH. API защищён общей сессией владельца Мастерской в AUTH_MODE=workshop либо прежним локальным сеансом в AUTH_MODE=password. Изменяющие запросы, включая DELETE, требуют X-CSRF-Token. Публичного доступа к источникам и результатам нет.

## Источники

- POST /api/stamp-sources — multipart с одним полем file, PDF/JPG/PNG. Загрузка разрешена до появления первого готового оттиска.
- GET /api/stamp-sources — `{items:[source]}`, новые загрузки первыми.
- GET /api/stamp-sources/{id} — один source.
- GET /api/stamp-sources/{id}/pages/{page}.png — PNG страницы, не более 1600 пикселей по ширине и 2400 по высоте.
- GET /api/stamp-sources/{id}/original — исходные байты с оригинальным именем файла.
- DELETE /api/stamp-sources/{id} — только явное удаление неиспользованного источника. Возвращает 409, если источник обрабатывается или связан хотя бы с одним сохранённым оттиском.

source содержит id, filename, source_type (`pdf`, `jpg`, `png`), size в байтах, created как Unix time, page_count, source_sha256, original_url и pages. Страницы имеют `{page,width,height}`; page начинается с нуля. Размеры — отображаемые пункты PDF либо пиксели изображения после учёта EXIF. Они предназначены для пропорций страницы; координаты выделения передаются нормализованными.

## Выделение и сохранение

POST /api/stamp-sources/{id}/extract принимает:

```json
{
  "page": 0,
  "crop": {"x": 0.35, "y": 0.25, "width": 0.30, "height": 0.40},
  "color": "blue",
  "strength": 50,
  "rotation": 0
}
```

crop задан в долях отображаемой страницы: x/y от 0 до 1, width/height больше 0 и не больше 1; область целиком находится внутри страницы. color: blue (синий/фиолетовый), red, dark. strength — целое число от 0 до 100. rotation — конечное число градусов от −15 до 15.

Ответ — прозрачный RGBA PNG с существующими пикселями оттиска, без дорисовки. Заголовки X-Source-SHA256 и X-Output-SHA256 связывают результат с исходником; X-Extraction-Coverage содержит долю выделенной области с видимыми чернилами. X-Extraction-Warnings — обычный JSON-массив строк с ASCII-экранированием Unicode, читаемый JSON.parse. Предпросмотр не меняет библиотеку и активный оттиск.

RGB полностью прозрачных пикселей очищаются до и после поворота: удалённый текст исходного документа не остаётся скрытым в скачиваемом PNG. Видимые и частично прозрачные пиксели сохраняются; приватный оригинал не изменяется.

POST /api/stamp-sources/{id}/save принимает те же параметры и обязательные name, company_name, company_inn, width_mm. Названия — от 1 до 120 символов; ИНН — 10 или 12 цифр, ширина — 20–60 мм. Сервер повторно извлекает PNG из постоянного оригинала и создаёт отдельный активный оттиск. Ответ совпадает с GET /api/stamps: `{items,active_id}`.

Новый элемент библиотеки содержит source_id, source_sha256, output_sha256, extraction (параметры выделения), extraction_result (размеры PNG, покрытие, предупреждения и параметры движка), source_url. GET /api/stamps/{id}/source возвращает оригинальный скан; для ранее загруженного готового PNG без скана отвечает 404. GET /api/stamps/{id}/image и совместимый GET /api/stamp/image продолжают отдавать готовый PNG.

Перед публикацией оба способа добавления проверяют готовый PNG по общему профилю: 16–4096 пикселей по каждой стороне, до 16 мегапикселей, отношение высоты к ширине 0,5–2. Слишком узкое выделение может быть показано в предпросмотре, но не станет активным оттиском; сервер вернёт 422, сохранив прежнюю библиотеку и исходный скан.

Полное декодирование готового PNG тоже выполняется в отдельном процессе через общий PDF slot. Занятая очередь отвечает 429 и сохраняет прежний активный оттиск; повторный запрос после завершения обработки разрешён.

Смена активного оттиска не меняет прежние элементы библиотеки, снимки печатей на документах или готовые версии PDF. Закрытие диалога выделения не удаляет оригинал. Пустая или слишком бледная область вызывает 422; чёрный текст возле тёмного оттиска может оставаться, о чём сообщается в предупреждении.

## Хранение и ограничения

Оригинал и UTF-8 manifest.json хранятся в приватном data/stamp-sources/{id}/ без TTL. MAX_JOBS ограничивает число источников отдельно от числа рабочих документов; MAX_TOTAL_MB общий для всех данных. Действуют MAX_UPLOAD_MB, MAX_PAGES и общий ограниченный процесс обработки. Один готовый PNG/предпросмотр ограничен меньшим из 8 МБ и MAX_RESULT_MB; изображения — до 24 мегапикселей, PDF-выделение — 300 dpi с бюджетом пикселей движка.

Парсинг, рендер и извлечение выполняются в отдельном процессе через общий PDF slot с лимитом времени. Для PNG резервируется место одновременно под временный файл и его отдельный результат. Каждая операция владеет собственной временной папкой; родитель удаляет её после успеха, ошибки или остановки процесса. Ошибка публикации PNG восстанавливает прежние настройки и удаляет только новый файл. Заполнение квоты блокирует новые операции, сохраняя исходники и уже готовые результаты.

Ответы: 401 — нет действующей сессии, 403 — CSRF/источник запроса, 404 — источник/страница отсутствует, 409 — источник занят или нужен для происхождения оттиска, 413 — размер запроса/PNG, 422 — формат или параметры, 429 — квота/очередь, 503 — общая авторизация недоступна, 507 — ошибка записи хранилища.
