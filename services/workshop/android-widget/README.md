# Android-виджеты VM

Приложение-компаньон для PWA `https://vm-app.ru/`. Версия 1.1.0 публикует в системном каталоге Android четыре независимых варианта:

- `Быстрые действия` 2×2 — расход, доход, производство и склад;
- `Сегодня` 4×3 — заказы и сроки, план производства, остатки склада;
- `Пульс бизнеса` 4×2 — финансы, заказы, клиенты и склад;
- `Модуль раздела` 2×1 — один выбранный пользователем раздел: финансы, заказы, цех или склад.

Можно разместить несколько вариантов и несколько модулей с разными настройками. Для модульного варианта Android открывает экран выбора после добавления, а на поддерживаемых лаунчерах его можно вызвать повторно через долгое нажатие.

## Безопасность

Виджеты не запрашивают сетевые разрешения, не хранят PIN, cookies и финансовые данные. Они содержат только фиксированные HTTPS-ссылки на `vm-app.ru`; авторизация остаётся внутри PWA. Живые суммы и рабочие показатели намеренно не показываются до появления отдельного безопасного API и локальной настройки приватности.

## Сборка

Требуются JDK 17 и Android SDK Platform 35. Проверка и сборка запускаются через зафиксированный Gradle Wrapper 8.7:

```text
gradlew.bat testReleaseUnitTest lintRelease assembleRelease
```

Релизная подпись передаётся только через переменные окружения:

```text
FINANCE_WIDGET_KEYSTORE
FINANCE_WIDGET_STORE_PASSWORD
FINANCE_WIDGET_KEY_PASSWORD
```

После сборки APK находится в `app/build/outputs/apk/release/`.

Подписанный APK версии 1.1.0 публикуется по адресу `https://vm-app.ru/downloads/finance-widget-1.1.0.apk`. Перед публикацией нужно проверить совпадение сертификата с предыдущей версией и контрольную сумму из соседнего файла `.sha256`.
