# Контракт Google Таблицы

Публичная карта без рабочих значений и идентификаторов таблиц.

| Область | Листы и ответственность |
| --- | --- |
| Заказы | `Заказы`, `Клиенты`, `Позиции`: клиент, состав, статус и расчёты |
| Финансы | `Платежи`, `Расходы`: подтверждённые операции; суммы и долг из формул |
| Производство v2 | `Производство · данные`: активная модель при `PRODUCTION_V2=google`, контракт `server/production-sheet.mjs` |
| Сохранённая модель производства | `Производство`, `Монтажи`, `Маршруты`: legacy этапы, монтажи и маршруты; не подменяют хранилище v2 |
| Склад | `Склад`, `Движения склада`: материалы, остатки, движения |
| Документы | Схема и заголовки определяются `server/document-sheets.mjs` |
| Настройки | `Настройки`: допустимые значения и справочники |

Общий адаптер проверяет имена листов, заголовки, типы и назначение колонок.
Формулы и расчётные поля не перезаписываются командами ввода.
Связи клиентов и заказов проверяются до записи. Пустое поле не равно нулю.
Долги и переплаты показываются раздельно; возвраты сохраняют свой смысл.
Историческая цена движения и текущая цена материала не взаимозаменяемы.

Записи проходят существующую очередь, защиту от повторов, проверку результата
и восстановление неопределённых операций. Новая схема требует явной миграции;
обычный запуск приложения не означает разрешение менять структуру листов.
Точные контракты: `server/finance-contract.mjs`, `server/finance-sheet.mjs`,
`server/document-sheets.mjs` и серверные модули соответствующей области.

Для интеграционных тестов используйте только отдельную разрешённую таблицу.
Примеры Google ID в публичном коде синтетические и не открывают рабочие данные.
