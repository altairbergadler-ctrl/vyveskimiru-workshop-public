# Локальный редактор и ИИ-генерация

Для серверной копии используйте [инструкцию VPS](../README.md). Ниже описан
локальный режим по умолчанию; доступ по домену настраивается отдельно через
`EDITOR_PUBLIC_ORIGIN` и защищённый HTTPS-прокси.

Калибровка `assets/calibrator.html` работает локально без сети. Для кнопки фотореалистичной генерации нужен **сервер навыка**, а не обычный статический сервер:

```powershell
& '<полный-путь-к-навыку>\scripts\start-server.ps1' -Port 54735 -OutputDirectory '<каталог-результатов>'
```

Прямой запуск: `python <skill>/scripts/render_server.py --port 54735 --output <каталог-результатов>`. Нужны Python 3.10+, Pillow, numpy, Node.js и установленный Codex CLI со входом через ChatGPT. `codex login status` должен подтверждать ChatGPT, а не API-key auth. `start-server.ps1` ищет комплектный Python, затем `python` в PATH. Сервер слушает только `127.0.0.1`, отдаёт только перечисленные файлы редактора и защищённые локальные маршруты. URL: `http://127.0.0.1:54735/calibrator.html`. При занятом порте проверь процесс; не завершай чужой сервер. В Windows при фоновом запуске через `Start-Process` используй `-WindowStyle Hidden` и запиши PID.

Для обычного открытия в Windows используй `scripts/open-editor.ps1 -OutputDirectory '<постоянный-каталог-результатов>'`. Он проверяет существующий процесс и каталог истории, запускает сервер скрыто при необходимости, ждёт готовности и открывает браузер. `-NoBrowser` позволяет проверить запуск без открытия окна. Журналы и PID нового процесса находятся в соседней с каталогом результатов папке `server`. При сообщении «Локальный сервер недоступен» запусти этот файл и нажми «Проверить подключение» в существующей вкладке: это сохраняет несохранённые фото и точки. Сам сервер после перезагрузки компьютера не запускается автоматически.

Порядок работы:

1. Загрузить фото JPEG/PNG/WebP. «Пример» открывает явно учебный векторный фасад с заданными размерами.
2. Выбрать режим. Для отрезка ввести его длину, отметить концы и включить допущение фронтального вида. Для прямоугольника ввести две реальные стороны и отметить углы по периметру.
3. Ввести габарит всей композиции и ТЗ. Для нескольких строк нажимать Enter в поле текста; выбрать межстрочный промежуток в сантиметрах и выравнивание. Ширина и высота относятся ко всем строкам вместе. Нажать «Указать центр вывески» и отметить его на фото.
4. При необходимости отметить четырьмя углами область установки. Инструмент проверит, входят ли заданные габариты; размер сам не меняется.
5. «Измерить» сохраняет отрезок с допущением, что он лежит в плоскости эталона. В других плоскостях этот результат использовать нельзя.
6. Сохранить проект JSON и техническую схему SVG/PNG. Для Codex передать исходное фото вместе с JSON. Фото не включается в JSON; схема включает его при экспорте из редактора.
7. Для изготовления из акрила с наклеенной плёнкой выбрать материал лица «Плёнка ORACAL на акриле»; серия, код, фактура, вид акрила и температура LED задаются отдельно. Неизвестные параметры оставить пустыми/не указанными. HEX остаётся экранным приближением, без автоматической привязки к вееру. В разделе «Фотореалистичный макет» выбрать исходное освещение, солнечный день, облачно или ночь. Для плёнки на акриле ночью свет идёт через лицевую часть; дневное включение задаётся отдельно. В режиме произвольного материала сохраняется подсветка по ТЗ и прежний контражур по умолчанию.
8. Отметить **зону замены** четырьмя углами или взять область установки. Розовый пунктир показывает, где разрешено убрать старую вывеску/помехи и восстановить фон. Включить весь габарит, тени и ореол, оставив окна и архитектурные границы снаружи. Сервер принимает локальную зону от 0,01% до 65% кадра.
9. В блоке «Через подписку ChatGPT / Codex» проверить подключение. Если вход отсутствует, войти через установленный Codex и нажать «Проверить подключение». Никаких API-ключей, токенов или паролей в редакторе вводить не нужно.
10. «Создать ИИ-макет» передаёт фото и ТЗ локальному Codex, который вызывает встроенную генерацию OpenAI за счёт лимитов подписки. Один клик — одно изображение, без автоматических повторов. Смена параметров не запускает запрос. Одновременно выполняется одна генерация. Сравнить готовый результат с исходником и световой основой, скачать PNG и отчёт защиты геометрии. Изменение параметров помечает предыдущий вариант как устаревший.

Точки считаются в исходных пикселях, независимо от масштаба отображения. Редактор хранит данные в памяти до закрытия вкладки: сохранение проекта явное. Импорт JSON восстанавливает точки и требования; затем загружается соответствующее фото. Совпадение размеров файла не доказывает совпадение изображения: проверь имя и видимые ориентиры.

Редактор сам не распознаёт объекты; это делает Codex через навык. Кнопка генерации запускает `codex --no-daemon ... exec --ephemeral` с существующей ChatGPT-авторизацией. Рабочая папка отдельная для каждого запроса; исходник и схема передаются встроенному `image_gen`. API fallback запрещён, автоматических повторов нет. Надпись технического эскиза — условный Arial с сохранением пропорций внутри габарита. Точный шрифт и цветовой код из ТЗ сохраняй в проекте.

## Защита исходника

Световая основа строится только покоординатными RGB-преобразованиями: без геометрических операций и перерисовки. Она задаёт общий вид дня/ночи, но не создаёт новое небо и глобальные солнечные тени. ИИ создаёт буквы, материалы, локальные тени/свечение и восстанавливает фон внутри зоны замены.

Для входа генератора допустимы уменьшенная копия и дополнение холста. Встроенный инструмент может вернуть другую разрешающую способность: допускается только равномерное приведение к размеру рабочего холста, с отклонением соотношения сторон не более 0,3% из-за округления пикселей. Другое соотношение сторон отклоняется. Исходник не масштабируется. Маска жёстко ограничивает вставку выбранным полигоном; растушёвка направлена внутрь. Вне него итог обязан побитно совпадать со световой основой. Отчёт сохраняет размер исходника/генерации, факт приведения разрешения, хеши и число изменённых пикселей вне зоны: должно быть 0.

Внутри зоны ИИ может отклониться от шрифта, размеров или линий поверхности. Защита внешнего кадра не доказывает точность букв и восстановленного участка. Техническая схема остаётся источником размеров. Эталон на другой глубине даёт только концепт.

## Файлы и проверка

Каждый запрос создаёт отдельный каталог с `source.png`, `lighting-base.png`, `edit-mask.png`, `project.json`, `prompt.txt`, `render-input.png`, `placement-guide.png`, `color-reference.png`, служебной схемой ответа Codex, затем `generated.png`, `render.png` и `audit.json` при успехе. Исходный пользовательский файл не перезаписывается. Каталог по умолчанию — `output/ai-generations` рабочего каталога. Авторизацией управляет сам Codex: редактор не читает и не копирует `auth.json`; API-ключи исключаются из окружения дочернего процесса.

Рабочий запуск Codex возвращает точный путь PNG, полученный от встроенного генератора. Локальный сервер проверяет этот файл и копирует его сам; запуск команд внутри рабочего Codex для копирования не требуется. Принимается только свежий PNG из разрешённого каталога встроенного генератора, а не произвольный путь или самый новый файл по догадке. `image-transfer.json` и аудит содержат хеши исходного и скопированного PNG. Сбой переноса готового изображения должен отличаться от ошибки самой генерации; повторять генерацию для переноса файла не нужно.

Рядом с результатом показаны цвета и материал из сохранённого задания этой генерации. Изменение формы не перекрашивает уже созданный макет. Фотореалистичное изображение не является цветопробой: свойства реальной плёнки, акрила и подсветки нужно сверять с физическим образцом.

ID выполняющегося запроса хранится в `sessionStorage`, чтобы после перезагрузки страницы проверить статус. История хранится на диске в папке результатов и доступна через отдельную страницу `history.html`; она восстанавливает и старые генерации, у которых есть `project.json`, `render.png` и `audit.json`. Новые задания дополнительно сохраняют `job.json` со временем и состоянием. Незавершённое задание после перезапуска показано как прерванное, а не продолжающееся. При разрыве связи генерация не повторяется автоматически: предыдущая попытка могла расходовать лимиты подписки.

В истории доступны поиск по надписи или ID, дата и освещение, миниатюры, просмотр сохранённых цветов и материала, скачивание PNG/JSON. Восстановление версии открывает её параметры и исходное фото в редакторе; новый запрос выполняется только по кнопке генерации. Не перезаписывай папки предыдущих версий. Для сохранения истории при запуске сервера указывай тот же каталог результатов.

Изображения в редакторе и истории вписываются в ограниченный по высоте предпросмотр с сохранением пропорций. Отдельный просмотр позволяет вписать кадр в окно или включить 100%, скачать оригинал и закрыть окно кнопкой или Escape. Миниатюра `thumbnail.jpg` создаётся отдельно; исходник и готовый PNG не уменьшаются.

Проверки без внешних вызовов:

```text
node <skill>/scripts/test-geometry.cjs
python <skill>/scripts/test_render_server.py
python <skill>/scripts/test_codex_render.py
```

Официальные источники: [встроенная генерация и общие лимиты Codex](https://learn.chatgpt.com/docs/image-generation), [повторное использование сохранённой авторизации в codex exec](https://learn.chatgpt.com/docs/non-interactive-mode). Это локальная интеграция с установленным Codex, а не подключение произвольного сайта к Images API через токен подписки. Прямой [Sign in with ChatGPT Responses-маршрут пока не поддерживает image generation](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).
