# Самостоятельные вывески в области установки

Владелец уточнил задачу: каждый текст/лого является отдельной вывеской,
ограниченной только отмеченной областью установки. Общая композиция с
внешними шириной, высотой, центром и поворотом больше не задаётся.

Новый режим `sign.composition_mode = independent_signs_v1`. В JSON v2 каждая
вывеска остаётся самостоятельным элементом `products[0].params.objects`;
канонический product и корневой mirror имеют `placement: null`. Этот контейнер
не является физической общей вывеской и не ограничивает геометрию объектов.
Координаты x_cm/y_cm относятся к плоскости калибровки, rotation_deg — собственный
поворот вокруг центра. Размеры, шрифты, материалы, точные PNG принадлежат элементу.

Геометрия и SVG проецируют каждый объект своей матрицей. Единственная
монтажная граница — `target_polygon_px`; для незавершённого редактирования
без области используется фото. Генерация требует явно отмеченную область и
проверяет отдельные рамки против неё и зоны замены. Производный report.placement
с derived:true — техническая сводка, не ограничение и не экранная рамка.
Свободный промежуток между удалёнными вывесками не должен сам помещаться в зону.

Открытый старый проект independent_objects_v1 мигрирует в редакторе с
сохранением физических размеров, ID, PNG и всех пиксельных углов, включая
общий и собственный повороты. Сохранённая серверная история не переписывается.
Черновики сохраняют новый mode, абсолютные позиции и незавершённое размещение.
Новые шаблоны используют restoreNew; обычный restore не угадывает геометрию.

Проверен реальный браузер на фото 46906.jpg: три вывески далеко друг от друга,
движение/поворот одной без изменений соседей, отсутствие общей рамки/размеров,
reload, JSON export/reimport и применение нового шаблона. Масштаб в примере
условный и используется только для проверки интерфейса.
