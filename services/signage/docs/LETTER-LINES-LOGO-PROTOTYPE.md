# Строки и логотип объёмных букв — прототип

Эта модель заменена по уточнению владельца. Актуальный прототип описан в
[INDEPENDENT-OBJECTS-PROTOTYPE.md](INDEPENDENT-OBJECTS-PROTOTYPE.md).
Ниже сохранено описание первого варианта.

12 октября 2026. Изолированная ветка `feat/letter-lines-logo`, база `a7b5be7`.
Рабочий сервис не менялся; перед началом подтверждён healthy образ
`channel-letter-mockups:20261012-assortment-v1`. Исходная рабочая копия
`assortment-modules` имеет чужие незавершённые изменения подсказок и не трогалась.

## Решение владельца

- Размер каждой строки — высота видимого текста в сантиметрах.
- Логотип свободно размещается внутри общей композиции.

## Доступно для проверки

Для каждой строки: отдельные высота, семейство шрифта и полужирное начертание.
Пустая высота означает «Авто». Заданная высота не уменьшается при переполнении:
расчёт сообщает ошибку. Общий габарит и межстрочный зазор сохраняют смысл.
Шрифты берутся с устройства; Canvas и SVG используют один способ выбора
семейства и замены отсутствующего шрифта.

Логотип загружается как PNG с прозрачностью до 1 МиБ. Ширина задаётся в см,
высота получается по пропорциям оригинала. X/Y считаются от верхнего левого
угла композиции; возможны наложение на текст и перетаскивание в перспективе.
Выход за габарит отклоняется. Удаление/замена оригинала явные; поздний ответ
загрузки не заменяет уже восстановленное или переключённое изделие.

Новые параметры находятся в `products[0].params.line_styles` и `.logo`, с
прежним зеркалом `sign`. Черновики и переключение изделий сохраняют параметры.
Без новых параметров прежняя геометрия остаётся прежней. SVG содержит строки
и оригинал логотипа. Проекты прототипа предназначены для этой копии редактора.

## Как открыть

`http://127.0.0.1:54760/calibrator.html`

Если сервер остановлен, выполнить из этой рабочей копии:

```powershell
python prototype-server.py
```

Кнопка «Вернуть учебный пример» возвращает фасад с двумя шрифтами и условной
чашкой. Это демонстрационный знак, не оригинал фирменного логотипа владельца.

## Проверки

- Node syntax изменённых JS, Python syntax сервера и `git diff --check`.
- Новые тесты композиции; прежние geometry, products, draft, viewport, ruler.
- Браузер: независимые высоты 28/12 см и изменение второго шрифта на Verdana;
  ошибки слишком большой высоты и выхода логотипа за рамку.
- Перетаскивание логотипа, Escape, восстановление высот/шрифтов/координат и
  оригинала после reload. Добавление средней строки сохранило Georgia у
  прежней второй строки, ставшей третьей.
- PNG без прозрачности отклонён; прозрачный PNG 240×160 загружен с шириной
  30 см и пропорциональной высотой 20 см.
- Ширины 390 и 320 px: document.scrollWidth 375 и 305 px, переполнения нет.
- Снимок: `qa/prototype-desktop.jpg`.

## Что требуется для рабочего выпуска после согласования интерфейса

Это прототип редактора и общей геометрии. ИИ и CorelDRAW отключены в его
интерфейсе; локальный HTTP сервер отвергает POST, подключения к VPS нет.

Перед выпуском необходимы версия обработчика/композиции и серверная проверка
новых полей, PNG через Pillow, размеры и ограничения сохранённого проекта.
Промпт должен учитывать отдельные строки и оригинал логотипа, без требования
единого масштаба. Точную лицевую графику логотипа следует накладывать
контролируемо после генерации. Нужен расширенный контракт Corel либо явное
ограничение экспорта новой композиции, чтобы не терять данные молча.

`letter-prototype.js`, баннер, локальный сервер и CSS скрытия каталога — только
для демонстрации; в рабочий выпуск их переносить нельзя. Persistent volumes,
авторизация, история и другие рабочие копии не изменялись.
