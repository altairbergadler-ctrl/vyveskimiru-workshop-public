# Лицевая часть букв для CorelDRAW 2024

Кнопка **«Создать и открыть в CorelDRAW»** передаёт параметры установленному
помощнику Windows. Он создаёт настоящий CDR в CorelDRAW 2024, сохраняет его в
**«Документы → Signage Corel»** и открывает с масштабом по всей надписи.
Буквы по умолчанию чёрные. При первом запуске браузер может попросить разрешить
открытие приложения. Если автоматическое открытие не сработало, нажмите
появившуюся ссылку «Открыть CorelDRAW» — это тот же запрос, без дубликата.
ZIP остаётся отдельным запасным способом. Linux-сервер не создаёт CDR.

## Установка помощника на Windows

Нужны CorelDRAW 2024, точный шрифт и полная установленная версия Python 3.10+
с `pythonw.exe`, папками `Lib` и `DLLs`. Из исходников проекта выполните:

```powershell
python scripts/corel_helper_install.py
```

Установка действует для текущего пользователя без прав администратора.
В `%LOCALAPPDATA%/SignageCorel` копируется собственная среда Python и проверенный
код. В HKCU регистрируется протокол `signage-corel`. Постоянного процесса,
автозапуска Windows и слушающего localhost-порта нет. Установщик не заменяет
чужую регистрацию этого протокола. Для отключения:

```powershell
python scripts/corel_helper_install.py --uninstall
```

Чертежи и установленные файлы при отключении не удаляются. На другом ПК
помощник устанавливается отдельно. Ссылка назначения фиксирована в помощнике:
`https://vm-app.ru/signs/`; при переносе домена нужна новая установка версии.
Технический журнал без билетов и паролей: `%LOCALAPPDATA%/SignageCorel/helper.log`.

## Открытие и диагностика

Помощник создаёт отдельную папку для каждого запроса: CDR, TXT с фактическими
размерами, XML и локальный скрипт. Подтверждение «Готово» на сайте появляется
только после отчёта помощника. Перезагрузка страницы лишь проверяет статус;
повторно Corel не запускает. Если браузер запретил внешние приложения,
разрешите открытие по своей кнопке или используйте ZIP. Помощник рассчитан на
обычный браузер Windows; поддержка внешних протоколов внутри встроенных браузеров
зависит от приложения.

Ожидание запуска — 5 минут, создание после получения задания — до 15 минут
на сервере; сам локальный вызов Corel ограничен 3 минутами. При таймауте
проверьте окно Corel и папку результатов: файл мог сохраниться. Автоматического
повтора создания нет. При потере подтверждения помощник повторяет только отчёт,
не сам CDR. Две одновременные активации сериализуются локальной блокировкой.

## Запасной способ: ZIP

1. В редакторе задайте текст, общую ширину и высоту, зазор между строками,
   выравнивание и название шрифта. Укажите, нужно ли полужирное начертание.
   По умолчанию — Arial и включённый Bold. Векторные буквы в CDR — чёрные
   (`#000000`); цвет макета на фото задаётся отдельно.
2. Скачайте пакет и распакуйте его целиком в отдельную папку с правом записи.
   Внутри находятся `layout.xml`, `Create-CDR.vbs` и русская `README.txt`.
3. На Windows должен быть установлен CorelDRAW 2024 и точный шрифт из ТЗ.
   При первом использовании запустите CorelDRAW обычным способом и завершите
   первоначальную настройку. Если шрифта нет, скрипт завершится сообщением;
   похожий шрифт автоматически не подставляется.
4. Откройте `Create-CDR.vbs` из распакованной папки. Скрипт создаст рядом
   `face-letters-YYYYMMDD-HHMMSS.cdr` и одноимённый TXT с фактическими размерами.
   Существующие результаты не перезаписываются.
5. Откройте CDR и проверьте текст, строки, шрифт, размеры, зазор и отчёт.

Для этого экспорта не нужны фото, генерация ИИ или подключённый Codex.
Рабочий вход в редактор нужен для скачивания пакета. Если Windows Script Host
отключён политикой компьютера или CorelDRAW недоступен для автоматизации,
скрипт не создаст CDR; не выдавайте готовый ZIP за уже полученный CDR.

## Размеры и состав чертежа

Документ имеет заданную ширину и высоту в сантиметрах, масштаб 1:1. Каждая
непустая строка создаётся из настоящего шрифта CorelDRAW и превращается в
кривые. Все строки масштабируются **одинаково и пропорционально**, чтобы
поместиться в рамку. Поэтому одна из сторон фактической надписи может быть
меньше рамки; растяжения букв по одной оси нет.

Зазор сохраняется в сантиметрах между рамками соседних строк. Строки
выравниваются слева, по центру или справа относительно страницы; композиция
центрируется по вертикали. Начальные и конечные пустые строки отбрасываются,
внутренние сохраняются: пустая строка получает высоту самой высокой непустой
строки при том же масштабе. Фактические размеры записываются в TXT.

Это плоские лицевые контуры без перспективы фотографии, глубины корпуса,
бортов, подсветки, фона и разметки. Скрипт не обводит ИИ-картинку. При экспорте
кнопкой редактора заливка чёрная независимо от лицевого цвета на фото;
контуры не получают обводку. Припуски и компенсация
реза не добавляются. Перед изготовлением проверьте макет, реальный шрифт,
обмер и требования оборудования; экранный цвет не является цветопробой плёнки.

## Серверный контракт

`POST /api/corel-package` (на VPS `/signs/api/corel-package`) требует тот же
вход, `Origin`, `Content-Type: application/json` и `X-Editor-Token`, что и
защищённые операции API. Успех: `200 application/zip`, имя скачивания
`letters-coreldraw-2024.zip`. JSON строго содержит эти восемь полей:

```json
{
  "text": "ОФИС ПРОДАЖ\nНЕДВИЖИМОСТИ",
  "width_cm": 220,
  "height_cm": 60,
  "line_gap_cm": 5,
  "text_align": "center",
  "font_family": "Arial",
  "font_bold": true,
  "front_color": "#000000"
}
```

Ширина и высота — больше 0 и до 10 000 см; зазор — 0–10 000 см и не занимает
всю доступную высоту. Текст — до 300 кодовых единиц UTF-16 и до 20 строк после
удаления пустых краёв. Шрифт — непустое имя до 120 символов без управляющих
знаков; `font_bold` — boolean, цвет — `#RRGGBB`, выравнивание — `left`, `center`
или `right`. Лишние поля и некорректные параметры отклоняются с HTTP 400.
Редактор всегда передаёт `front_color: "#000000"`. Прямые API-клиенты могут
по-прежнему передавать любой цвет `#RRGGBB`; сервер сохраняет этот цвет в XML.

`corel_export.py` создаёт ZIP в памяти, не сохраняет задание в истории и
не запускает внешние программы. Пользовательские параметры сериализуются в
XML как данные; постоянный скрипт не меняется от текста надписи. В ZIP скрипт
кодируется UTF-16 с BOM для Windows Script Host. В пакет не включаются фото,
полный проект, пароль, ключи или авторизация Codex. XML-парсер скрипта запрещает
DTD и внешние сущности.

## Реализация и проверка

`assets/corel-export.js` собирает форму, запускает помощника и проверяет статус; также скачивает ZIP.
`scripts/corel_export.py` проверяет вход и упаковывает данные.
`scripts/corel/Create-CDR.vbs` подключается к `CorelDRAW.Application.25`,
проверяет установленный шрифт, создаёт строки и сохраняет документ.

В реальном CorelDRAW 2024 (версия 25) проверен двухстрочный кириллический макет:
страница 220 × 60 см, зазор 5 см, цвет `#DDFFEA`. Файл повторно открыт; две
строки представлены кривыми (`Shape.Type = 3`), габарит страницы точный,
композиция примерно 180,339 × 60 см и расположена по центру. Меньшая ширина
является результатом пропорционального вписывания настоящего шрифта.
Это проверка конкретного примера; она не подтверждает все шрифты или готовность
любого макета к производству. Полный журнал проверок выпуска — в
[TESTING.md](../TESTING.md).

Использованные методы описаны в официальной документации CorelDRAW 2024:
[создание художественного текста](https://community.coreldraw.com/sdk/api/draw/25/m/layer.createartistictext?lang=vb),
[преобразование в кривые](https://community.coreldraw.com/sdk/api/draw/25/m/shape.converttocurves)
и [сохранение документа](https://community.coreldraw.com/sdk/api/draw/25/m/document.saveas).
