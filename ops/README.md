# Серверные обработчики

Эти программы сверены с действующими каталогами VPS 22 октября 2026 года.
Значения настроек и рабочие данные хранятся отдельно и в комплект не входят.

| Каталог | Назначение |
| --- | --- |
| `mail-runner/` | Почтовый проход Codex, дельта писем, prompt, schema и инструкции |
| `max-codex/` | Действующий мост MAX-помощника, ретушь изображений, schema и подготовка runtime |
| `drive-backup/` | Зашифрованное резервирование в Drive, восстановление и политика хранения |
| `systemd/` | Фактически установленные unit/timer файлы связанных процессов |
| `static-paused-crm/` | Страница временно отключённого отдельного CRM |

Unit-файлы используют существующие абсолютные серверные пути и пользователей.
Перед установкой на другой сервер необходимо создать соответствующие аккаунты,
закрытые каталоги настроек, runtime и точки монтирования.
Секреты передаются защищёнными файлами вне этого checkout.

`drive-backup/` содержит также административные программы удаления и retention.
Они сохранены как исходники и не запускаются тестовой сборкой.
Политика удаления требует отдельного подтверждения точных целей и восстановления.

Основные средства выпуска, резервирования Мастерской и Caddy находятся также
в `services/workshop/deploy/`. Инструкции каждого сервиса остаются
в его собственном каталоге. Полная конфигурация Caddy с посторонними сайтами
и закрытыми параметрами сюда не копировалась.
