# Мастерская «ВывескиМиру»

Полный комплект исходников действующих приложений `vm-app.ru` и связанных
серверных обработчиков, обновлённый 22 октября 2026 года. Это публичная копия исходников.

| Каталог | Приложение | Адрес / назначение |
| --- | --- | --- |
| [services/workshop](services/workshop/README.md) | Основной сервер и PWA | Финансы, заказы `/kanban/`, клиенты, производство, склад, аналитика Авито, почта и MAX |
| [services/signage](services/signage/README.md) | Визуализация вывесок | `/signs/`, история проектов, CorelDRAW, коммерческие предложения |
| [services/stamp](services/stamp/README.md) | Документы и печати | `/tools/stamp/`, PDF/JPG/PNG, подписи, история документов |
| [apps/calculator](apps/calculator/README.md) | Калькулятор букв | `/calculator/` |
| [apps/fonts](apps/fonts/README.md) | Каталог шрифтов и примерка | `/fonts/`, 228 семейств, примерка по фото и AR |
| [ops](ops/README.md) | Серверные обработчики | Почта, мост MAX/Codex, systemd, резервирование и Drive |

Google Таблица остаётся бизнес-хранилищем и расчётной моделью.
SQLite содержит техническое состояние, сессии, очередь и квитанции.
Визуализация и печати работают отдельными сервисами; калькулятор и шрифты —
отдельными статическими приложениями.

## Начало работы

Основное приложение: Node.js 22.22.0 или совместимая версия 22.x.

```sh
cd services/workshop
npm ci
cp .env.example .env
# Настройте локальное окружение и отдельную тестовую Google Таблицу.
npm run check
npm run dev
```

Для визуализации и печатей используйте Dockerfile, compose-файлы и инструкции
в соответствующих каталогах. Реальные доступы передаются отдельно.
Инструмент печатей запускается без предустановленной настоящей печати:
загрузите свой PNG через интерфейс после настройки входа.

Шрифты содержат исходные TTF, лицензии, код сборки и готовый `dist/`.
Калькулятор также хранит готовое статическое приложение в `dist/`.

```sh
cd apps/fonts
npm ci --ignore-scripts
npm run build
npm run test:geometry

cd ../calculator
npm test
```

## Развёртывание и источники

Архитектура основного приложения:
[services/workshop/ARCHITECTURE.md](services/workshop/ARCHITECTURE.md).
Контракт Google:
[services/workshop/docs/SHEETS_CONTRACT_MAP.md](services/workshop/docs/SHEETS_CONTRACT_MAP.md).
Сборка и установка основного сервера выполняются из `services/workshop/`
его штатными `qa/package-release.mjs` и `deploy/install-workshop.sh`.
Сборка этого репозитория сама по себе ничего на VPS не устанавливает.

Версии и результаты проверки собранного комплекта:
[docs/SNAPSHOT.md](docs/SNAPSHOT.md).
Файлы отдельных сервисов сохраняют свои исторические checkpoint и release notes;
описанное в них состояние относится к указанной там дате.

Пароли, токены, Google service account, авторизация Codex, базы данных,
документы заказов, макеты, история генераций, подписи, настоящие печати,
закрытые резервные копии и финансовые записи в Git не включены.
В `services/workshop/server/bootstrap-data.json` оставлен пустой массив вместо
старого неиспользуемого набора финансовых записей.

Публичная история начинается с очищенного снимка действующих сервисов.
Подробная внутренняя история сохраняется в закрытом исходном репозитории.
Идентификаторы таблиц, почтовые адреса и реквизиты по умолчанию заменены
синтетическими примерами; перед запуском настройте собственное окружение.
Подробности: [docs/PUBLICATION.md](docs/PUBLICATION.md).
Прежняя локальная история Git, ветки и рабочие каталоги сохранены на исходном ПК.
Музыкальные приложения и другие посторонние сервисы сюда не входят.
Устаревший отдельный CRM отключён; его страница-заглушка сохранена в `ops/`.

## Лицензии

Репозиторий содержит компоненты с разными условиями использования.
Лицензия инструмента печатей находится в `services/stamp/LICENSE`.
Лицензии шрифтов сохранены рядом с файлами шрифтов и в публичных assets.
Зависимости сохраняют свои лицензии; наличие в этом комплекте
не меняет их условий.
