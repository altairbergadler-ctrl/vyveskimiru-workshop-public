Gitleaks скачан из официального выпуска с проверкой SHA-256 по опубликованному
списку контрольных сумм. В `.gitleaks.toml` заданы две узкие группы исключений:
локальный каталог `.assembly/`, который не входит в Git, и строка
с идентификатором `categories-v1` в двух файлах основного сервера. Это открытый
маркер миграции, ошибочно определяемый как API-ключ.

Node-зависимости для локальной проверки подключались из существующих проектов;
они игнорируются Git. Python-зависимости установлены в отдельное локальное
виртуальное окружение. В GitHub Actions каждый компонент получает собственную
установку зависимостей по своим lock/requirements-файлам.

Сохранено предупреждение исходной сборки PWA о размере JS chunk; оно не блокирует
сборку. В Python-зависимостях также выводятся предупреждения об устаревающих API.
Код приложений не менялся ради скрытия этих предупреждений.

Это проверка переноса исходников. Новый выпуск на VPS, реальная рассылка,
генерация за деньги, работа AR на телефоне и запуск CorelDRAW в этой задаче
не выполнялись. Результат GitHub Actions оценивается отдельно после отправки.

Python-проверки GitHub Actions используют Python 3.12.15 и Node 22.23.3,
как действующий Dockerfile визуализации. Для тестов согласованности букв
важна база Unicode 17 в Node: первоначальная настройка Node 22.22.0 выявила
различие классификации 28 новых символов. Версия CI приведена к действующему
runtime, исходники приложения не менялись. Задания Python независимы друг
от друга: сбой одного не отменяет проверку второго.
