с узкой областью `/calculator/`, без обработчика fetch и без кеша. При первом входе
помогает версия `?v=standalone-v1` на CSS, основном модуле и импорте формулы.
При обновлении меняйте эту версию во всех четырёх местах (включая регистрацию worker).

## Откат

Команда по SSH:

```sh
python3 /srv/signage-cost-calculator/deploy/install-static.py --rollback /srv/signage-cost-calculator/deployment-20261012-standalone-v1.json
```

Удаляется только точный блок маршрута калькулятора из текущей настройки Caddy;
остальные актуальные блоки сохраняются. Кандидат валидируется до замены,
сохраняется дополнительная копия, выполняется reload и возвращается прежняя ссылка.
Если блок изменился либо Caddyfile меняется во время проверки, команда останавливается.
Сами выпуски и резервные копии не удаляются. Для первой установки предыдущего
калькулятора нет: откат отключит его маршрут.

## Следующая установка

`install-static.py` предназначен для первоначального добавления маршрута:
повторная установка обнаружит существующий `/calculator` и остановится.
Для обновления уже установленного статического каталога сначала проверьте manifest
текущего выпуска, подготовьте новый неизменяемый выпуск, затем атомарно переключите
`current` с сохранением прежнего target. Caddy повторно менять не требуется.
